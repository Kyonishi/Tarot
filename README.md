# 星夜塔罗

一个无需登录、打开网页即可使用的塔罗牌工具原型。

## 当前功能

- 单牌与三牌阵（过去 / 现在 / 未来）
- Rider–Waite–Smith 78 张牌组
- 正位 / 逆位
- 牌面翻转、洗牌、星尘与月相动画
- 占问内容与抽牌历史保存在浏览器本地
- 历史记录查看、删除、清空与 JSON 导出

## 使用

直接打开 `index.html` 即可运行，不需要构建工具或服务器。

## 图片来源

牌面使用 Rider–Waite–Smith 原版公开牌图，图片地址来自公开的 tarot-api 镜像仓库：

https://github.com/sixseeds/tarot-api

原始牌面由 Pamela Colman Smith 绘制，最初于 1909 年出版。正式公开发布前，仍应根据目标发布地区复核公版状态。

网页运行时使用 `cards-webp/` 中的压缩牌图；原始 JPG 保留在 `cards/` 目录作为素材源。

## 数据说明

抽牌历史只保存在当前浏览器的 `localStorage` 中，不会上传到服务器。
